# 拆到能指导新片，而不是写观后感

## 观察尺度随问题改变

`reference --frames 8`只能提供全貌导航。动作是否完成、文字是否闪过、切点前后是否连贯需要局部连续证据，不能从稀疏帧补猜。用 `scripts/run.py evidence <视频> --start <秒> --end <秒> --fps 4` 查看局部，短暂事件改用 `--every-frame`。每段≤10秒且≤120帧，超过上限就缩小范围或分段；不能把低频采样称为连续逐帧。返回的index可浏览帧组并播放带原声的clip；先读摘要，再按问题查看必要图像。manifest中的source_time才是实际源帧时间，reference中的time只是请求的导航位置。ASR仍未接入；若宿主无法播放或听音频，保留未验问题，不假造转写。

先看全片中观众的问题怎样提出、怎样得到回答，再细看关键转折。只在会改变新片设计的区间补证据；不要无差别对全片逐帧送模型。参考时间、源素材时间与新片时间分开，最终时长跟随新片真实口播/动作。

对要迁移的机制记录：

|源区间与证据|实际变化|对观众的作用（解释）|在新片保留什么|需要的本地素材|如何检查|
|---|---|---|---|---|---|
|实际看到的起止时间、帧/片段路径|哪段话、哪个对象、哪个动作/文字进入或退出|例如先展示结果，让后面的步骤有目标|关系或次序，避免机械复制秒数|必须看见的动作、包装或来源|新片在对应语句时是否展示了相应证据|

没有看到或听到的栏位写未知。若只有静帧，不能把“物体位置不同”直接写成某种运镜；帧差、光流、频谱均不能独立证明AI制作来源或配乐生成方式。

## 能迁移的是关系

“节奏快、镜头高级、前三秒吸引人”不能指导选片。进一步问：开场给了什么具体信息？后文是否兑现？画面是说明、证明、对照，还是装饰？字幕与动作是否同时争夺注意力？关键画面是否留到观众读懂？

保留参考片有用的关系，同时根据示例品牌真实材料重写。案例仅说明方法：参考片先展示操作结果再讲步骤，新片可先展示正确封口状态再讲操作；但储存条件、可保存时长必须另有产品事实，不能从参考片继承。

如果参考只提供美术灵感，就只迁移配色/层级等被用户需要的部分，不强加它的剧情、促销、运镜或时长。没有热度快照就称参考片；机制解释不能写成“保证爆款”的因果结论。

把证据、解释、适配选择分开保存到本作品creative-notes。传给story的是可执行要求和素材缺口，不是长篇形容词，也不是原片全文复述。
