# ADR-004：证据驱动的编辑判断与片段覆盖

日期：2026-10-09。状态：提示词与coverage修复已实施；新增运行时Harness契约待设计，不视为已实现。

背景：用户要求深入吸收参考项目的提示词和agent harness；首轮编排与文件门禁不能证明业务创作质量。源码研究和取舍详见HARNESS_RESEARCH。

决策：按需增加参考近看、编辑决策、具体批评和恢复指引；同一宿主使用现有CLI。复杂任务的creative-notes由宿主维护，用于保存意图、依据、锁定项、版本和未决问题，不作为机器已批准状态。不引入模型服务、每阶段子agent、完整第三方DSL或全流程反复审批。

已复现缺陷：coverage按整文件时长认可匹配动作，且Top5早于时长筛选。修正契约：指定query时，匹配词必须在同一标注value中且该标注区间至少满足需求时长；不跨时间拼词。先按视频类型和区间筛选，再取5个候选；返回usable_ranges及证据。无query只证明文件技术长度。duration必须是(0,600]内有限数值，拒绝bool和非数字。

影响评估：原始媒体/资产清单/SQLite格式不变；无数据迁移；search默认返回不变；coverage增加usable_ranges且更保守地报告缺口。不得自动把旧方案的coverage结论视为仍已验收，应重跑；缓存原有已渲染镜头仍可复用，运行时实现指纹使新render形成新revision。现有批准历史保留，不自动为旧成片重新背书。没有新网络调用、依赖、部署或外部费用。

替代方案：用整文件长度过宽，已实际误判；将所有匹配标签时段相加会制造连续动作不存在的假覆盖；自动视觉语义评分目前没有可用模型与校准集。采用同一标注连续区间的保守判断，并由宿主实际看画面核实；跨标签联合语义和排序算法后续独立设计。

验证：覆盖短标注/长文件、不同时间分散关键词、首5个无效而后续有效、空查询、异常时长；运行全套回归。Prompt增加8个行为评测案例，但未执行模型A/B，不能声称成片质量提升。未来上下文装配器、密集证据工具、创作状态与语义锚点须先冻结各自契约再实施。
