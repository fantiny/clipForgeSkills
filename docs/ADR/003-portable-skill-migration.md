# ADR-003 可执行 Skills 移植基线

状态：Accepted for implementation（2026-10-09用户授权按开发指导执行移植）。业务事实和经营目标仍待确认。

决策：当前目录建立可安装Python CLI和共享Skills。固定提交的原有vidmake只做确定性合成，通过隔离进程和显式配置接收审定方案。最小v1支持顺序视频轨、独立字幕及跨镜音轨，原声keep/mute；尚未支持的变速、转场、工程导出必须拒绝，禁止静默忽略。后续扩展需Schema版本和回归。

重大影响：新增本地SQLite与不可变JSON版本；不迁移/覆盖旧素材库，旧表只读导入。审核绑定计划、事实、素材和实际输出指纹。业务资料改变或输出损坏将使审核失效。缓存仅复用相同输入和工具版本且输出哈希完整的阶段。运行失败不能沿用旧输出冒充成功。

发布边界：技能源保存在skills，宿主目录由安装器创建（原链接方案已由[ADR-009](009-windows-native-runtime.md)的受管理副本替代）。只在项目内安装。运行时引擎保留提交出处，未取得明确分发条件前不随包分发源码。没有网络服务、账号和外部AI计费依赖。

被拒绝方案：纯提示词包装fvm make仍会重新规划；重写全套剪辑引擎增加重复维护；每阶段独立agent增加上下文消耗。现有 fvm compose 的 --config 分发限制由进程适配器解决，不修改上游工作树。

最小契约先在schemas和docs/API.md记录；按照DEVELOPMENT_PLAN分阶段实现与测试。技术样例和生产交付为不同状态，不能相互冒充。

验证阈值应用：本轮代码复杂度≤10、运行时文件≤500行、整体覆盖≥70%、核心≥90%。用户明确要求的业务指导与开发计划保留为验收依据，初期文档/代码文件数量比例不作为删除这些交付物的理由；避免增加重复文档，以计划维护唯一状态台账。
